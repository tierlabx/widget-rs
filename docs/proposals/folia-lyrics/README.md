# 提案 PROP-001：沉浸式桌面流光歌词小部件 (Folia Lyrics)

> **当前状态**：方案评审中 (Review / RFC)  
> **灵感来源**：[chthollyphile/folia-major](https://github.com/chthollyphile/folia-major)（高质感沉浸式动效歌词播放器）与现代音乐文字 PV（Typography Music Video）  
> **目标架构**：Rust + GPUI 原生桌面渲染引擎  

---

## 1. 提案背景与产品定位

### 1.1 背景痛点
桌面音乐歌词通常分为两种极端：
- **简陋型**：仅有一行半透明悬浮文字或简单 LRC 滚动，视觉呆板、无节奏动效与舞台沉浸感。
- **庞大型**：基于 Electron/WebGL（如 Folia-Major 原版），虽然视效惊艳，但常驻内存动辄 350MB~600MB，且作为独立应用窗口容易被系统 `Win+D`（显示桌面）隐藏，难以自然融入桌面壁纸生态。
- **缺乏感染力**：现有歌词软件多局限于“文本逐字变色”，缺少类似“音乐文字 PV”（Typography PV）中震撼的字词弹性进场、节奏重音爆破、空间景深冲撞与排版律动。

### 1.2 本组件核心定位
将现代“音乐文字 PV”顶级的排版视觉艺术、Folia-Major 的流光舞台感与 `widget-rs` 的“轻量、常驻、高性能”深度结合：
- **文字 PV 级动态表现力 (Typography PV Visuals)**：
  - **字词级弹簧进入 (Per-Word Spring Pop)**：每个字词发音瞬间产生微位移悬浮与弹性缩放敲击，带来如同文字 PV 般的清脆节奏打击感。
  - **全屏沉浸舞台排版**：当前演唱主句居中放大聚焦，历史句向上缓退漂移微缩，预备句下方微光蓄势；间奏时自动进入声波律动，全屏展开时呈现电影级文字舞台。
  - **双层霓虹辉光 (Active Neon Glow)**：高饱和度高光点亮，配合 12px 动态流光晕染与呼吸光效。
- **超轻量化运行**：利用 GPUI + DirectComposition 硬件加速，内存控制在 **30MB~50MB** 以内，CPU 闲置占用低于 0.3%，支持 120Hz 高刷屏丝滑帧率。
- **双模架构 (Listener + Standalone)**：
  - **全局媒体监听模式 (SMTC Listener，主力场景)**：零配置、免登录。用户使用网易云、QQ音乐、Spotify、Apple Music、Foobar2000 或浏览器播放音乐时，小组件自动捕获曲目与进度，秒级完成逐字歌词匹配并呈现沉浸式流光舞台。
  - **本地独立模式 (Standalone，进阶场景)**：支持将本地 flac/mp3/wav 音频文件拖入小部件直接播放。
- **原生融入桌面**：通过 `Progman` 挂载实现 `Win+D` 桌面常驻不消失，配合 DirectComposition 玻璃拟态实现直通壁纸的通透质感。

## 2. 核心功能特性矩阵

| 功能维度 | 核心特性说明 |
| :--- | :--- |
| **文字 PV 视觉** | 全屏沉浸文字 PV 舞台模式、极简单行卡拉OK、唱片桌面胶片模式、直通壁纸玻璃模式 |
| **字词弹性进场** | 逐字毫秒解析（YRC / QRC / TTML），字词进入触发 $1.0 \to 1.25 \to 1.0$ 阻尼回弹敲击与微浮动 |
| **动态镜头排版** | 当前主歌词黄金焦点放大，历史与预备行景深衰减与视差位移，间奏声波律动保护 |
| **双层霓虹辉光** | 未唱字呼吸微光、已唱字高饱和度点亮与 12px 柔和扩散流光光晕过渡 |
| **弹性动力学** | 切行采用 Underdamped Spring（刚度 240.0，阻尼 22.0）驱动，平滑吸附无生硬跳帧 |
| **自适应流体舞台** | 动态提取专辑封面三色色盘，Lissajous 曲线驱动 3 轴漫反射光球与节奏呼吸 |
| **系统媒体联动** | 深度接入 Windows SMTC，单调时钟连续时间外推，双向控制（播放/暂停/切歌/跳转） |
| **智能歌词源** | 本地二级缓存 + 网易云/LrcLib 多源自动降级链（逐字 YRC 优先） |
| **桌面规范遵从** | 严格遵循 `WidgetWindow<T>` 封装、Win+D 桌面常驻、单文件 ≤ 400 行、独立设置弹窗 |

## 4. 实施路线图 (Milestones)

### Phase 1: 歌词解析与核心排版渲染
- [ ] 构建 `YrcParser` / `LrcParser`，支持标准逐行与精确毫秒逐字时间戳及翻译。
- [ ] 实现基础 GPUI 歌词列表组件：当前行高亮、自动居中滚动、上下渐隐蒙版。
- [ ] 接入高精度时间外推器（单调时钟补偿 SMTC 进度抖动）。

### Phase 2: 文字 PV 动效管线与全屏舞台
- [ ] 实现字词级弹跳算法（`WordTiming` 进场缩放 $1.0 \to 1.25 \to 1.0$ 与微位移浮动）。
- [ ] 在 GPUI 自定义 Canvas Element 中实现双层文本遮罩（`with_mask`）与霓虹光晕扫光。
- [ ] 实现文字 PV 动态排版引擎（主焦点放大居中、上下句景深衰减与切行 Spring 吸附）。
- [ ] 动态色盘提取与 3 轴 Lissajous 漫反射流光舞台背景。

### Phase 3: Windows SMTC 全局媒体捕获与网络歌词
- [ ] 基于 `windows` crate 实现 `GlobalSystemMediaTransportControlsSessionManager` 监听。
- [ ] 实时解析外部播放器封面、歌名、歌手、播放状态与播放进度。
- [ ] 接入多源歌词检索机制，支持本地缓存与在线匹配（网易云 YRC 逐字 / LrcLib）。

### Phase 4: 桌面级打磨与规范合入
- [ ] 规范化包装入 `WidgetWindow<T>` 容器，支持全屏 PV 舞台与窗口化切换，保持 `Win+D` 常驻。
- [ ] 编写符合规范的独立设置弹窗（动效强度、舞台模式切换、字号、流光强度等）。
- [ ] 执行 `cargo clippy`、`cargo fmt`、内存与 CPU 压力基准测试，保证每个文件 ≤ 400 行。
