# Folia 歌词：架构与 GPUI 文字 PV 动效渲染管线

本文档详细规划如何在 `gpui` 原生桌面渲染框架下，构建具备**文字 PV (Typography Music Video)** 级视觉表现力的全屏与桌面歌词动效管线，包括字词级弹簧跳入、动态镜头与景深排版、双层霓虹辉光遮罩及流光舞台背景。

---

## 1. 总体渲染架构与分层

小部件的视觉层次自底向上划分为五层：

```
+-------------------------------------------------------------+
| Layer 5: 控制层与信息浮标 (SMTC 状态/曲目信息/控制按钮/设置入口)   |
+-------------------------------------------------------------+
| Layer 4: 文字 PV 动效核心层 (字词弹跳敲击 + 动态镜头景深排版)      |
+-------------------------------------------------------------+
| Layer 3: 霓虹辉光与扫光遮罩 (双层 Dual-layer Neon Glow + 粒子微光)|
+-------------------------------------------------------------+
| Layer 2: 动态色盘流光舞台背景 (自适应封面提取色 + 动态高斯弥散)     |
+-------------------------------------------------------------+
| Layer 1: 暗角弥散与透明通道 (Backdrop Vignette + DirectComposition)|
+-------------------------------------------------------------+
```

## 2. 核心算法一：文字 PV 字词级弹跳敲击 (Per-Word Spring Pop & Drift)

传统的歌词通常只做“文字从左向右机械变色”，缺乏音乐的“节奏打击感”。在文字 PV 管线中，每个词都是一个具有物理张力的粒子。

### 2.1 逐字时间片与弹簧冲击模型
对于一条逐字歌词（YRC/QRC）：
```json
{
  "text": "沉浸在桌面里的每一个音符",
  "words": [
    { "word": "沉浸", "start_ms": 1200, "duration_ms": 400 },
    { "word": "在",   "start_ms": 1600, "duration_ms": 250 },
    { "word": "桌面", "start_ms": 1850, "duration_ms": 500 }
  ]
}
```

当前播放时间戳为 $T$。对于当前正在发音或刚发音完毕的词（设起始时间为 $T_{start}$）：
定义相对发音时间差 $\Delta t = (T - T_{start})$（单位：秒）。

#### 1. 敲击缩放 (Scale Pop)
在发音的前 180ms 内，字词触发高阻尼弹性冲击：
$$Scale(\Delta t) = 1.0 + 0.26 \cdot e^{-16 \Delta t} \cdot \cos(24 \Delta t)$$
- **冲击初速度**：字词在被唱响的瞬间，字号骤增至 $1.26\times$，产生清脆明快的“节拍敲击感”。
- **平滑吸附**：在 180ms 内迅速回弹吸附至 $1.0\times$ 稳定常态。

#### 2. 轻盈浮动 (Y-Drift & Lift)
发音期间字词获得向上 $4\text{px}$ 的反重力上浮位移，并在字词持续期结束时平滑回落，模拟音乐发音时的共鸣悬浮。

## 3. 核心算法二：动态双层霓虹辉光扫光 (Dual-layer Neon Glow Mask)

### 3.1 遮罩管线实现
在 GPUI 的自定义 Canvas / Element（`impl Element for TypographyPvElement`）绘制阶段：
1. **底层（未播文本 - Base Track）**：
   - 绘制半透明灰白色静态文本（`rgba(255, 255, 255, 0.38)`），并施加轻微低频呼吸微光（Alpha 在 $0.35 \sim 0.45$ 循环）。
2. **顶层（激活文字 - Active Neon Glow Track）**：
   - 采用封面提取的高饱和度主光色（或霓虹亮白），在激活区域 $[0, X_{progress}]$ 内使用 `cx.with_mask(ContentMask { bounds: active_rect })` 裁切绘制。
   - **辉光散射过渡 (Edge Glow Blur)**：在当前扫光前沿边缘叠加宽度 14px 的径向线性渐变羽化层，并叠加二次微发光通道，消除生硬硬边。

## 4. 核心算法三：动态镜头与文字 PV 空间排版 (Camera & Layout Dynamics)

文字 PV 的最大魅力在于**空间排版与动态镜头推拉**：

### 4.1 黄金视线焦点与景深抛物线
在全屏沉浸与大窗口舞台下，视野中同时呈现多行歌词：
- **当前激活行（Focus Line）**：
  - 位于垂直黄金分割点（约 $46\%$ 高度），字体超大（36px~48px），字重加粗，不透明度 $1.0$，具备字词弹跳动效。
- **历史行（Previous Lines）**：
  - 向上缓退漂移，字号阶梯式缩小（$24\text{px} \to 18\text{px}$），不透明度依指数衰减（$0.4 \to 0.15$），字间距轻微收紧，形成向纵深退去的空间感。
- **预备行（Upcoming Lines）**：
  - 在下方微光蓄势，字号中等（$22\text{px} \to 16\text{px}$），不透明度较低（$0.3 \to 0.1$）。

### 4.2 弹簧阻尼切行 (Underdamped Spring Transitions)
切歌或歌词切行时，避免机械滚动：
$$F = -k(y - y_0) - c \cdot v$$
- **刚度 $k = 240.0$**，**阻尼 $c = 22.0$**。
- 当歌词跃迁至下一行时，镜头整体平滑推升，上一行以优雅的倾角弧度向上滑出焦点，新行弹性吸附至黄金视线。

### 4.3 间奏律动保护 (Break / Instrumental Protection)
遇到歌曲长间奏（无歌词时间超过 4 秒）时：
- 自动过渡为**纯音乐流光律动模式**：文字渐隐，画面中心唤醒动态律动声波光环（Orb Pulsing），保持舞台生机，绝不出现空白冷场。

## 5. 核心算法四：自适应流光动态舞台背景 (Dynamic Flow Stage)

### 5.1 封面色盘提取与调和
- 从专辑封面动态提取 3 个代表色（Dominant 主色、Accent 强调色、Muted 暗底色）。
- 进行 HSL 空间明度与饱和度安全截断，防止底色过刺眼影响歌词可读性。

### 5.2 多层动态径向渐变混合 (Lissajous Light Orbs)
在背景层使用自定义 Canvas 绘制：
- 维持 3 个浮动的椭圆渐变漫反射光源，各自遵循低频正弦/余弦轨迹缓缓漂移。
- 结合节拍脉冲（Beat Pulse），轻微呼吸缩放光源半径（$\pm 6\%$）。
- 四周施加径向暗角弥散（Backdrop Vignette），确保文字具有极高对比度。

---

## 6. 性能与功耗优化标准

1. **零开销空闲态 (Zero-CPU Idle)**：
   - 音乐暂停超 3 秒，动画帧循环归零，进入纯事件驱动休眠。
2. **局部脏标记重绘**：
   - 仅高亮行与背景光晕重绘，历史上下文歌词复用 Layout 缓存。
3. **内存控制**：
   - 封面图片与色盘计算后台异步处理，内存稳定控制在 30MB~50MB。
