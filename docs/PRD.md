# Widget RS 桌面组件系统 - 产品需求文档 (PRD)

## 1. 产品概述
“Widget RS” 是一款基于 Rust 原生渲染（GPUI）的现代化桌面小部件系统，严格遵循 VoltAgent 的深空极客暗黑美学。它包含一个统一的管理主窗口和多个可悬浮在桌面上的独立小部件（便签、待办事项）。旨在为开发者和专业用户提供一个极致美观、响应迅速且功能专注的桌面效率工具，并具备面向未来的插件可扩展性。

## 2. 目标用户
* 开发者、工程师、注重生产力和桌面美学的极客玩家。
* 需要高频记录备忘、管理任务，且偏好暗黑主题与终端界面质感的用户。
* 有开发能力，希望通过编写自定义小部件来扩展桌面功能的高级用户。

## 3. 设计语言与界面风格
采用 **VoltAgent 设计系统**，营造“AI 时代的深空指令终端”氛围：
* **核心色彩**：极黑画布 (`#050507`)、碳纤维层 (`#101010`)、强调色翡翠绿 (`#00d992`)、边框约束暖碳灰 (`#3d3a39`)。
* **排版系统**：`system-ui` (标题)、`Inter` (正文)、`SFMono-Regular` (代码)。
* **视觉层级**：通过 1-3px 边框厚度、翡翠绿发光特效（Glow）以及小部件边缘的模糊投影（Blur Shadow）来构建空间深度，避免沉闷。
* **动画与过渡**：所有交互（Hover、状态切换、窗口显隐）均要求平滑流畅的现代动画过渡（由 GPUI 动画曲线支持）。

## 4. 核心功能模块划分

### 4.1 管理主窗口 (Main Window)
系统控制中枢。
* **侧边栏**：切换管理分类（便签、待办、全局设置、插件市场）。
* **主内容区**：对应小部件的详细配置、预览或插件市场的浏览界面。

### 4.2 便签小部件 (Sticky Note Widget)
* **窗口形态**：轻量级独立悬浮窗口（默认 320x360），圆角 8px，无系统默认边框（Frameless）。
* **功能**：快捷记录文本代码。浅色反差背景（`#fef3c7`）区分于主体的暗黑风格。

### 4.3 待办事项小部件 (Todo List Widget)
* **窗口形态**：独立悬浮窗口（默认 360x400），圆角 8px，无边框。
* **功能**：待办条目的增删改查、完成状态勾选。极黑背景配合翡翠绿的高亮交互。

### 4.4 窗口与系统级交互 (System-Level Interactions)
* **始终置顶 (Always on Top)**：用户可配置各个小部件是否保持在最顶层，避免被其他窗口遮挡。
* **边缘吸附与透明度 (Edge Snapping & Transparency)**：
  * 支持小部件拖拽至屏幕边缘时自动吸附。
  * 支持静置或靠边时调节透明度（例如半透明以减少视觉干扰，鼠标悬浮时恢复不透明度）。
* **鼠标穿透 (Mouse Passthrough)**：支持用户配置小部件是否允许鼠标点击穿透。开启后，鼠标操作将穿过小部件作用于下层窗口，进一步降低对日常工作的干扰（可通过系统托盘菜单快捷切换该状态）。
* **系统托盘 (System Tray)**：提供系统状态栏图标，支持右键菜单，用于快速隐藏/显示所有小部件或完全退出程序。

### 4.5 插件生态系统 (Plugin Ecosystem)
* **第三方开发能力**：平台需提供标准化的插件接入方式，方便开发者利用提供的 UI 组件库和接口编写独立的小部件功能（如系统监控、天气、股票等）。
* **插件市场 (Plugin Market)**：主窗口内置插件市场模块，支持在线浏览社区开发的插件，实现一键下载、安装、启用和更新。

## 5. 数据存储说明
* **纯本地存储 (Local Storage Only)**：当前版本设计**完全摒弃云端同步**，所有用户数据（便签内容、待办列表、全局设置、窗口位置与吸附状态）以及**已下载的本地插件包**均以极轻量的格式持久化在本地用户目录下，保证极致的安全与响应速度。
