# 常见问题 (FAQ)

本页面记录了 Widget-RS 用户及开发者常遇到的问题及解答。

## 通用使用问题

### Q: 小组件挡住了我的其他窗口，怎么取消置顶？
**A**: 请打开主面板，在侧边栏选择“全局设置”，找到“始终置顶”选项并关闭。

### Q: 我无法点击小组件下方的图标或文本？
**A**: 可能是你开启了“鼠标穿透”功能。该功能开启后，小组件会完全透传鼠标点击。请在系统任务栏/托盘找到 Widget-RS 的图标，右键取消“开启鼠标穿透”即可恢复正常操作。

### Q: 如何移动无边框的便签或待办事项？
**A**: 请在系统托盘菜单中选择“开启编辑模式”，小组件顶部会出现一条绿色的拖拽指示条，拖动该指示条即可调整小部件在桌面上的位置。

## 开发者与编译问题

### Q: 在 Windows 编译时报错：`link.exe` 找不到？
**A**: 请确保你安装了 Visual Studio Build Tools，并且勾选了“Desktop development with C++”（C++ 桌面开发）工作负载。

### Q: 为什么我在插件的 `view.rs` 中看不到处理窗口拖拽的代码？
**A**: 因为 Widget-RS 的底层 `WidgetWindow` 容器接管了所有的窗口外框和编辑逻辑。插件只需关注其核心内容的渲染（即实现 `WidgetContent` 特征）。详见 [小组件规范.md](小组件规范.md) 和 [插件开发指南.md](插件开发指南.md)。

### Q: 我可以给插件增加华丽的标题栏吗？
**A**: **不推荐**。本项目追求沉浸极简的设计（参考 VoltAgent 风格）。我们强制要求摒弃传统的常驻标题栏，采用无边框体验。

### Q: 如何贡献代码？
**A**: 请先阅读项目根目录下的 `CONTRIBUTING.md`，提交 PR 时请遵循约定式提交（Conventional Commits），如 `feat: add new widget`。
