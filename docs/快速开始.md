# 快速开始 (Getting Started)

欢迎使用 Widget-RS！本项目是一个基于 Rust 和 GPUI 构建的高性能、高可扩展的现代桌面小部件系统。

## 环境准备

在开始之前，请确保你的系统满足以下条件：

1. **Rust 工具链**：请安装最新版（Stable）的 Rust。你可以通过 [rustup](https://rustup.rs/) 安装。
2. **C++ 构建工具**：
   - **Windows**：安装 Visual Studio Build Tools，并勾选 C++ 开发工作负载。
   - **macOS**：执行 `xcode-select --install`。
   - **Linux**：安装必要的开发包（如 `build-essential`, `pkg-config`, `libx11-dev` 等）。

## 获取代码与运行

1. **克隆项目**
   ```bash
   git clone https://github.com/your-username/widget-rs.git
   cd widget-rs
   ```

2. **运行项目**
   ```bash
   cargo run --release
   ```
   *注意：使用 `--release` 参数可以获得极致流畅的性能体验和更低的内存占用。*

## 如何使用小部件

* **主面板**：启动应用后，将会弹出管理面板，您可以在此管理所有的插件和配置。
* **编辑模式**：在系统托盘右键菜单中，点击“编辑布局”进入编辑模式，小部件上方将出现绿色拖拽条，此时你可以自由拖动和调整它们的位置。
* **添加插件**：参考 [插件开发指南.md](插件开发指南.md) 了解如何通过 `widget-cli` 安装和卸载本地小部件。
