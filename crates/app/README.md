# Widget RS App Crate

`widget-app` 是 `widget-rs` 项目的应用程序主干模块，负责整个桌面端应用程序的生命周期和系统集成。

## 主要功能

- **入口与生命周期管理**：提供程序的 `main` 入口点，初始化 GPUI 运行上下文。
- **配置与数据存储** (`config`)：提供全局配置加载和序列化功能。
- **窗口管理** (`window`)：封装桌面级窗口管理行为，包括 GPUI 原生句柄对接及特定平台（Win32）底层调用，控制小组件的始终置顶、鼠标穿透、Z 轴层级。
- **插件调度** (`plugin`)：集中管理小组件插件（Plugin）的生命周期、注册机制和激活状态。
- **系统集成** (`system` & `tray`)：系统托盘的生成和控制、以及基于注册表的开机自启动逻辑。
- **资产挂载** (`assets`)：应用基础资产与资源（如图标等）的注入。

## 架构

此模块只处理框架逻辑与底层环境（Windows API 等），不包含具体的 UI 渲染实现。UI 界面的工作全权委托给 `widget-ui`。
