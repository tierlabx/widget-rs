# Widget RS Core Crate

`widget-core` 是 `widget-rs` 的核心通用层，承载了所有基础的数据结构和 Traits。

## 主要功能

- **公共数据结构**：应用级别的全局配置 (`AppConfig`) 和各类实体抽象。
- **插件接口定义**：定义小部件开发的核心标准，包括插件元数据、通讯信道机制和统一行为规范。
- **UI 原语交互**：提供部分基础状态机、原子变量（如 `NATIVE_EDIT_MODE` 等），以便不同的 Crates（如 app, ui 和各类 plugins）之间可以安全地进行状态同步。
- **跨模块交互桥梁**：确保 App 运行时与业务逻辑层/UI 层实现无缝解耦。

## 设计原则

此模块应当保持最小依赖，不直接处理特定操作系统接口或庞大的界面渲染库，任何小部件和功能模块都可以通过该 `core` 实现扩展。
