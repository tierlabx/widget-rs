# Widget RS CLI Crate

`widget-cli` 是 `widget-rs` 的辅助构建与管理工具。它是一个独立的命令行应用程序（CLI），用于简化开发者在开发小组件（Plugins）和管理项目过程中的复杂操作。

## 主要功能

- **自动化构建**：处理自动化发布日志 (Changelogs)、约定式提交验证 (Conventional Commits)。
- **开发提效工具**：能够快速脚手架化（Scaffolding）一个新的小部件，或者对现有的配置进行验证。
- **构建环境保障**：包含项目开发中的一些环境检测或脚本执行能力。

## 注意事项

该工具并非 `widget-rs` 运行时的依赖，其主要在开发阶段和构建/发布流 (CI/CD) 中被调用。
