## [0.1.4](https://github.com/tierlabx/widget-rs/releases/tag/widget-ui-v0.1.4) - 2026-08-05

### Added

- initialize project crate structure and plugin workspace configuration
- implement main window UI and navigation structure with window management utilities
- implement sticky note and todo list plugins with markdown rendering and LMDB storage support
- initialize crates and plugin project structure with Cargo manifests
- 加载vrm 模型
- implement main window layout with custom titlebar and navigation sidebar
- 增加3d插件
- implement main window UI with sidebar navigation and Win32 window controls
- 自动重新聚焦了一次,系统托盘切换显示隐藏

### Fixed

- 修复插件安装卸载问题
- 修复fmt错误
- 修复release
- 修复顶部缩放问题
- 修复鼠标穿透，等问题
- 打磨与升级
- 修复开机启动功能bug
- 修复启动项问题
- 修改设置
- 小部件设备修改
- 更换logo
- 完成排版时保存
- 优化logo
- 修复崩溃bug
- 修复warning
- 实现大部分功能
- 组件化
- 主程序工具栏问题
- 增加编辑模式
- 更新目录结构

### Other

- release
- 重构插件加载硬编码问题
- release v0.1.0
- 更新文档，规则，修复warning
