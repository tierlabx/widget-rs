# Widget RS UI Crate

`widget-ui` 模块包揽了 `widget-rs` 项目中除了具体各个插件本身逻辑之外的“核心交互界面”，基于 GPUI 框架搭建。

## 主要功能

- **控制面板（主窗口）**：渲染整个软件的管理大盘（Dashboard），包括左侧导航边栏、全局通用布局（Layout）、窗口标题栏。
- **页面视图**：实现具体的视图层功能，例如小组件管理页（Widgets）、设置页（Settings）和首页仪表盘（Dashboard）。
- **通用组件库**：提供供全局或各插件复用的 UI 原语，如按钮、开关（Toggle）、卡片（Card）、微章（Badge）等，确保产品具备一流的视觉一致性和现代化动画美学。
- **事件绑定**：配合 `widget-app` 将 UI 操作与底层持久化、窗口置顶设置以及状态切换进行联动。

## UI 规范

为了保持最佳性能和界面一致性，所有视图应严格遵循本库中定义的 `layout::*` 和 `components::*` 构建，不建议通过编写孤立的特化布局污染全局风格。
